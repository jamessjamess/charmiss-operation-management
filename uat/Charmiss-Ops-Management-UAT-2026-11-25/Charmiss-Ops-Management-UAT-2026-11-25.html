Flow หลังรวมระบบ

ออเดอร์ → ยืนยัน → ตรวจ Quota + WMS (ATP แสดงวันที่ของจะพอ) → SO Request → SLA ส่ง SO/IV (หัก Quota ครั้งเดียว) → WMS พร้อมส่ง → ส่งมอบขนส่ง (ระหว่างขนส่ง) → Delivered (Sales In) → คืนสินค้า ดี/เสีย → WMS รับคืน → ดึง WMS → Supply Planning (อ่านอย่างเดียว) → ข้อเสนอ → อนุมัติ → Draft ใน Flow เดิมของ Ops

WMS Actual เป็นแหล่งข้อมูลจริง · การส่งมอบ / ผลขนส่งไม่แก้ Actual · Supply ไม่สร้าง SO / IV / CN และไม่จองหรือหัก Quota · ทุกอย่างที่ Supply ส่งกลับเป็นข้อเสนอที่ต้องมีผู้อนุมัติ (ผู้สร้างอนุมัติเองไม่ได้)
